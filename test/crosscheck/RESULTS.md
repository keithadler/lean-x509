## Notes

- rustls-webpki checks keyCertSign on its main branch (rustls/webpki#452, fixed by #510), which is not in the current stable release, 0.103.15.
- NSS is exercised through `vfychain`, NSS's own verifier. Firefox validates with mozilla::pkix on top of NSS, so its answers can differ.
- LibreSSL is the macOS system `openssl` (3.3.6, an old release); its `verify` has no host-name option, so the host cases are n/a.
- These are leniencies, not vulnerabilities: every flaw here sits inside bytes the CA signed, except the three unsigned-wrapper cases, which change a certificate's bytes without changing what it says.
